# DSA – Data Structures and Algorithms

## 📚 About This Repository

This repository contains my practical implementations of Data Structures and Algorithms (DSA) for the CA3 assignment.

The main objective is to understand and implement fundamental data structures using Java.

## 💻 Programming Language
- Java

## 📂 Submission 1 – Stack and Queue

This submission includes the following implementations:

| No. | Program | Description |
|---|---|---|
| 1 | QueueStackPush.java | Stack implementation using Queue with efficient Push operation |
| 2 | QueueStackPop.java | Stack implementation using Queue with efficient Pop operation |
| 3 | UnboundedArrayStack.java | Dynamically resizing Array-based Stack |
| 4 | StackQueueEnqueue.java | Queue implementation using Stack with efficient Enqueue operation |

## 🎯 Learning Objectives

- Understand Stack and Queue data structures.
- Implement Stack using Queue.
- Implement Queue using Stack.
- Understand Push, Pop, Enqueue and Dequeue operations.
- Learn dynamic array resizing.
- Improve problem-solving and programming skills.

## ▶️ How to Run

1. Clone this repository.
2. Open the project in Visual Studio Code.
3. Compile the Java file:

   `javac FileName.java`

4. Run the program:

   `java FileName`

Replace `FileName` with the relevant Java class name.
